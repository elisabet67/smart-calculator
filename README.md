# 🧮 스마트 전자계산기 (환율보기 & 단위변환)

실시간 환율 조회/계산과 9대 분류 단위 변환을 완벽하게 지원하는 스마트 다기능 전자계산기 프로그램입니다.

---

## 🚀 빠른 실행 방법

### 방법 1: 바탕화면 폴더에서 바로 실행 (가장 추천)
- **`계산기_실행.bat`** 또는 **`run.bat`** 파일을 더블클릭합니다.
  - 별도의 복잡한 설치 없이 즉시 실행됩니다.
  - Windows High-DPI 선명도 지원 및 다크 테마 GUI가 표시됩니다.

### 방법 2: 명령 프롬프트 / 파워셸에서 실행
```bash
python main.py
```

### 방법 3: 웹 브라우저에서 바로 사용
- **`index.html`** 파일을 더블클릭하면 Chrome, Edge 등 브라우저에서 즉시 동일한 기능을 사용할 수 있습니다.

---

## ✨ 주요 기능 및 특징

### 1. 🧮 전자계산기 (Calculator)
- **기본 사칙연산**: 덧셈(+), 뺄셈(-), 곱셈(×), 나눗셈(÷)
- **공학 및 특수 연산**:
  - 거듭제곱 (`^`), 제곱 (`x²`), 제곱근 (`√`)
  - 괄호 연산 (`(`, `)`)
  - 부호 반전 (`±`)
  - 삼각함수 (`sin`, `cos`, `tan` - Degree 각도 기준)
  - 로그 (`log` 상용로그, `ln` 자연로그)
  - 원주율 (`π`), 자연상수 (`e`)
- **키보드 완벽 지원**:
  - 숫자패드 및 상단 숫자키
  - `+`, `-`, `*`, `/`, `^`, `(`, `)`
  - `Enter`: 계산 실행 (`=`)
  - `Backspace`: 한 글자 지우기 (`⌫`)
  - `Escape`: 전체 초기화 (`C`)

### 2. ⚖️ 단위 변환기 (Unit Converter)
- **9개 주요 카테고리 지원**:
  1. **길이 (Length)**: mm, cm, m, km, inch, ft, yd, mile, 해리, 자(척), 간, 정, 리
  2. **넓이 (Area)**: m², km², a, ha, ft², yd², acre, **평(坪)**, 단보(反), 정보
  3. **무게 (Weight)**: mg, g, kg, t, oz, lb, **돈(금 1돈=3.75g)**, 냥, **근(600g)**, 관
  4. **부피 (Volume)**: mL/cc, L, m³, fl oz, cup, pt, qt, gal, 홉, 되, 말
  5. **온도 (Temperature)**: 섭씨(°C), 화씨(°F), 켈빈(K)
  6. **데이터 (Data)**: bit, B, KB, MB, GB, TB, PB
  7. **속도 (Speed)**: m/s, km/h, mph, knot, ft/s, Mach(마하)
  8. **압력 (Pressure)**: Pa, hPa, kPa, bar, psi, atm, mmHg/Torr
  9. **시간 (Time)**: ms, s, min, h, d, wk, yr
- **실시간 양방향 변환**: 값을 입력하는 즉시 목표 단위로 자동 환산
- **단위 맞바꾸기(⇄)** 원클릭 버튼
- **일괄 변환표**: 선택한 값 1개를 기준으로 해당 카테고리의 **모든 단위 환산 결과를 한눈에 표로 비교** 제공

### 3. 💱 실시간 환율 보기 & 환율 계산기 (Exchange Rate)
- **실시간 환율 연동**:
  - 무료 공공 환율 API 실시간 동기화
  - 비동기 백그라운드 업데이트로 UI 멈춤 현상 제로
  - 오프라인/네트워크 불안정 시 로컬 캐시 환율로 자동 전환
- **양방향 통화 환산**:
  - 원하는 금액을 입력하면 기준환율에 따라 즉시 변환
  - 1단위당 기준환율(매매기준율) 안내
- **원화(KRW) 기준 전 세계 주요 통화 환율표**:
  - 미국 달러(USD), 일본 엔(JPY 100엔 기준), 유럽 유로(EUR), 중국 위안(CNY), 영국 파운드(GBP), 호주 달러(AUD), 캐나다 달러(CAD), 스위스 프랑(CHF), 홍콩 달러(HKD), 대만 달러(TWD), 베트남 동(VND) 등
  - **표에서 원하는 통화를 더블클릭하면 계산기 통화로 자동 세팅**되는 스마트 인터랙션
- **수동 새로고침 버튼 (`🔄`)**: 언제든 최신 환율 즉시 재동기화

### 4. 📜 계산 기록 (History)
- 이전 계산 수식과 결과 자동 보존
- 목록에서 원하는 수식을 **더블클릭하면 계산기로 바로 불러오기** 가능
- 원클릭 기록 삭제 기능
